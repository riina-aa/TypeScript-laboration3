# Laboration3

I denna laboration har jag skapat en responsiv webbapplikation med Angular och TypeScript. Webbplatsen består av tre undersidor: en startsida, en kalkylator och en informationssida som beskriver arbetsprocessen.

Kalkylatorn gör det möjligt att konvertera temperatur mellan Celsius och Fahrenheit samt längd mellan meter och fot, i båda riktningarna. Funktionaliteten är implementerad med TypeScript och Angulars tvåvägsdatabindning (ngModel), vilket gör att resultaten uppdateras automatiskt när användaren anger ett värde.
